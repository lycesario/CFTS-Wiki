00怎么读这份图谱

投融资平台最容易做错的地方，是一上来就做「撮合」。先把四层结构看清，再决定你做哪一层。

四层结构

层级内容产品本质
主体与资产层融资方企业/项目/资产、投资方机构/基金/LP、股权与份额「谁在找钱、谁在给钱」。这一层不清晰，后面所有匹配都是噪音
交易与流程层发现 → 匹配 → 尽调 → 谈判 → 投决 → 签约 → 交割 → 投后 → 退出「把一次交易从偶发变成可复制」。价值来自流程确定性，不是界面好看
资金与份额层出资、托管、划付、交割结算、份额登记、收益分配「钱与权的变更」。容错率接近零，与金融科技的账务底座同源
数据与合规层企业情报、市场数据、估值基准、AML、合格投资者、监管报送、审计留痕「凭什么信、凭什么过审」。这一层决定平台能否被机构与监管接受
三条先决判断（比功能清单更重要）：
① 你是 A 撮合型 / B 机构内部投管 / C 政府国资 / D 资产交易 中的哪一种——四种定位的产品骨架差异极大，混做一定失败。
② 是否触达资金与份额——一旦涉及出资托管、份额登记、收益分配，就进入强监管区，容错空间骤降。
③ 交易天然保密——投融资的信息敏感性远高于一般行业，权限、水印、审计不是加分项，是入场券。
投融资平台特有的死亡陷阱：为了「看起来热闹」而把项目信息公开化。优质项目方最怕的就是融资消息被同行和员工看到， 一旦平台无法保证定向披露，最好的供给会立刻流失，平台退化成劣质项目的市场——这是绝大多数撮合平台折在这里的原因。

09如果要做，从哪开始

全景的价值在于收敛。先选定位，再砍功能域，最后砍到能动手的粒度。

收敛四步
  • 第一步 · 选定位：A 撮合型 / B 机构内部投管 / C 政府国资 / D 资产交易。四条路的页面结构与合规路径完全不同。
  • 第二步 · 定资产：一级股权、债权、资产交易、基金份额——只选一类，不同资产的条款体系差异极大。
  • 第三步 · 定边界：碰不碰资金（出资托管、划付）、碰不碰份额（登记、分配）、碰不碰公开信息（披露）。三个答案决定牌照与架构。
  • 第四步 · 定冷启动：投融资平台是双边市场，先做供给还是先做需求，决定你是从工具切入还是从数据切入。
四类常见起步路径
  • 从工具切入（推荐给新团队）：先做单边工具——数据室与尽调协作、投后数据报送、股权台账。不触达资金、不依赖双边网络，靠真实客户验证痛点后再向交易层延伸。
  • 从数据切入：以投融资事件库、机构画像、估值基准为切入，用数据订阅养活平台，再逐步承接交易撮合。
  • 从场景嵌入：绑定一类产业（如医疗、硬科技）或一类场景（如国资招商），做垂直深度而非横向广度。
  • 做双边撮合（最难）：需要同时解决优质供给与有效需求，冷启动期长、烧钱快，除非已有渠道资源，否则不建议作为第一站。
